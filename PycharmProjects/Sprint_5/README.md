Тестирование веб-приложения Stellar Burgers

Описание проекта
Этот проект представляет собой набор автоматизированных тестов для веб-приложения Stellar Burgers. Тесты разработаны для проверки функциональности сайта, включая регистрацию, вход в систему, выход, навигацию по разделам конструктора и профиля пользователя.

Используемые технологии
Python 3.13.3 — язык программирования.
Selenium WebDriver — инструмент для автоматизации взаимодействия с веб-страницами.
pytest 8.3.5 — фреймворк для написания и запуска тестов.
webdriver-manager — библиотека для автоматической загрузки и управления веб-драйверами.

Структура проекта
tests/ — директория с тестовыми файлами:
test_registration.py — тесты регистрации пользователей.
test_login.py — тесты входа в систему.
test_logout.py — тесты выхода из системы.
test_constructor_navigation.py — тесты навигации по конструктору.
test_constructor_sections.py — тесты разделов конструктора.
test_profile_navigation.py — тесты навигации по профилю.

locators/ — модуль с локаторами элементов на страницах.
helpers/ — вспомогательные функции (генерация случайных email и паролей).
test_data/ — тестовые данные (пользовательские данные).

Запуск тестов: pytest tests -v

Требования
Python 3.13.3 или выше.
Google Chrome (для работы Selenium WebDriver).
Установленный ChromeDriver (управляется через webdriver-manager).

Результаты тестирования
Все тесты успешно проходят, проверяя ключевые функции сайта Stellar Burgers, такие как регистрация, вход, выход и навигация. Текущий статус: 12 тестов пройдено.
